# Groove Scribe (Ben's version)

Based on Groove Scribe by Lou Montulli and Mike Johnston (GPL v2, see LICENSE.txt),
https://github.com/montulli/GrooveScribe.

Changes in this version:
- 4 toms in the editor (Tom 1 high, Tom 2 mid, Tom 3 low, Tom 4 floor)
- Per-bar time signature (e.g. 4/4 and 3/4 in one groove): 'time' menu above each bar. URL: &MeasureBeats=4,3
- Per-beat grid (1/4, 1/8, 1/16, 1/32): 'beat' menus above each bar. Choosing 1/32 for one beat keeps the other beats at their grid.
