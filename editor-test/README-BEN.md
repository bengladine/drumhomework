# Groove Scribe (Ben's version)

Based on Groove Scribe by Lou Montulli and Mike Johnston (GPL v2, see LICENSE.txt),
https://github.com/montulli/GrooveScribe.

Changes in this version:
- 4 toms in the editor (Tom 1 high, Tom 2 mid, Tom 3 low, Tom 4 floor)
- Time signature per bar (two menus above each bar: beats / note value), e.g. 4/4 then 7/8. URL: &Meters=4/4,7/8
- Grid per beat: 1/4, 1/8, 1/16, 1/32, triplets, sextuplets — mix them per beat (32nds and triplets can't be combined in one groove)
- Bars wrap like a sheet
- Bar tools: play from this bar, loop bar(s), move left/right, duplicate, clear, delete; '+' asks: copy of last bar or empty bar
- Changing the subdivision on the left keeps the notes when they fit
